# SDR# SWL Frequency Database

> **RELEASE WITHDRAWN**
>
> The initial files published in this repository contained only 97 entries and did not meet the stated scope of a comprehensive worldwide SDR# SWL database. They have been removed to prevent further distribution.
>
> Please do not use or redistribute the withdrawn ZIP, XML, CSV, or XLSX files. A properly sourced and validated replacement has not yet been published.

## Current status

No usable database release is currently available from this repository.

The replacement must be built from current, attributable sources; contain the promised large-scale coverage; use an SDR#-compatible XML structure; and be tested by loading it in SDR# rather than merely checking that the XML is well formed.
